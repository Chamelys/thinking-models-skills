# Cognitive Skills Repository

个人思维模型 Skill 集合 - 用于系统化地存储和管理各种认知思维模型。

## 目录结构

```
cognitive-skills/
├── README.md                    # 仓库总说明
├── INDEX.md                     # 所有Skill的索引目录
├── templates/
│   └── SKILL_TEMPLATE.md       # 新建Skill时的模板
├── skills/
│   ├── five-dimension-analyzer/ # 五维五层分析器
│   │   └── SKILL.md
│   ├── first-principles/        # 第一性原理思维
│   │   └── SKILL.md
│   ├── ooda-loop/              # OODA循环
│   │   └── SKILL.md
│   └── ...                     # 更多Skill
└── CHANGELOG.md                # 版本更新日志
```

## 使用说明

1. **查看已有 Skill**: 浏览 `skills/` 目录
2. **新建 Skill**: 复制 `templates/SKILL_TEMPLATE.md` 并填写内容
3. **更新索引**: 修改 `INDEX.md` 添加新 Skill 的条目

## 现有 Skill

| Skill 名称 | 描述 | 路径 |
|-----------|------|------|
| 五维五层分析器 | 多层次的系统性分析工具 | `skills/five-dimension-analyzer/` |
| 第一性原理思维 | 回归事物本质的思考方式 | `skills/first-principles/` |
| OODA循环 | 观察-判断-决策-行动的快速决策模型 | `skills/ooda-loop/` |
