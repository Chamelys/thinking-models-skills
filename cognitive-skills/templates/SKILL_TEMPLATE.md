# Skill Template

新建 Skill 时的标准模板。复制此文件到新 Skill 目录，填写所有 `TODO` 项。

---

```markdown
# [Skill 名称]

## 概述

[一句话说清楚这个 Skill 解决什么问题]

## 使用场景

- [场景 1]
- [场景 2]
- [场景 3]

## 核心概念

### [概念 1]
[解释]

### [概念 2]
[解释]

## 使用方法

### 基本步骤

1. 步骤一
2. 步骤二
3. 步骤三

### 示例

[提供一个具体的使用示例]

## 最佳实践

- [实践 1]
- [实践 2]
- [实践 3]

## 常见误区

- [误区 1]
- [误区 2]

## 相关 Skill

- [相关 Skill 名称 1]
- [相关 Skill 名称 2]

## 参考资料

- [来源 1]
- [来源 2]
```

---

## 填写说明

1. **概述**: 简洁明了，控制在 1-2 句话
2. **使用场景**: 列出 3-5 个典型使用场景
3. **核心概念**: 解释关键概念，帮助理解原理
4. **使用方法**: 提供清晰的步骤和示例
5. **最佳实践**: 分享经过验证的有效做法
6. **常见误区**: 指出容易犯的错误
7. **相关 Skill**: 链接到其他相关的认知模型
8. **参考资料**: 列出来源和延伸阅读

## 命名规范

- Skill 目录名使用小写英文，单词间用连字符分隔
- 例如: `first-principles`, `ooda-loop`, `design-thinking`
